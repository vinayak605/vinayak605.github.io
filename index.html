J.I.N.X — Judgmental Intelligence with Neural eXecution

Autonomous AI desk robot · B.Tech final year project, Data Science

A desk-mounted robot that sees, hears, speaks, and judges — combining 10 machine learning models across computer vision, audio classification, NLP, and sensor fusion. It recognizes faces, tracks people with pan-tilt servos, detects environmental sounds like glass breaking or sirens, holds Gemini-powered conversations in a human-sounding voice, answers questions about uploaded documents, and reviews code on save — all running on hardware salvaged from a dead ThinkPad and a broken phone.

"Its metal chassis became J.I.N.X's body. A spare phone that couldn't make calls became its eyes, ears, and voice. Total hardware cost: ₹4,550."
PythonYOLOv5-nanoMediaPipeTensorFlow / Keras dlib · face_recognitionVosk STTedge-TTSGemini 2.0 Flash ESP32 / C++MQTTFlaskStreamlitscikit-learn
  • Real-time face detection & recognition with colour-coded threat status (safe / unknown / flagged)
  • 33-point skeleton pose estimation and 21-point hand gesture control
  • Custom CNN trained on UrbanSound8K to detect gunshots, sirens, glass breaking, screams
  • Offline wake-word detection ("Hey JINX") with full voice command control
  • Gemini-powered conversation with a persistent sarcastic personality
  • Document Q&A and live code review agent over a watched project folder
  • TFT display with 12 animated eye states, synced pupil-tracking to detected faces
  • Pan-tilt head servos that physically follow people
  • VL53L0X time-of-flight sensors for millimetre-accurate table-edge detection
  • Dual ultrasonic + ToF obstacle avoidance and automatic battery management
  • WS2812B reactive LED strip with 11 mood-based animation modes
  • Flask web control panel — any phone on the network can drive the robot, no app needed
  • Streamlit "cyberpunk" dashboard with live camera feed, skeleton view, and network map
  • Five operating modes: Buddy, Sentinel (surveillance), Roast, Agent, and Sleep
